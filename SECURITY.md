# Security

Murmur keeps audio and text on the Mac: speech-to-text and cleanup both run on device, and nothing is sent over the network. A bug that breaks that promise counts as a security issue, as does anything that lets another app or a dictated phrase take control of Murmur.

## Reporting

Please report privately through GitHub's [Report a vulnerability](https://github.com/chihanlow/murmur/security/advisories/new) form rather than a public issue. Expect a reply within a week. Only the latest version on `main` gets fixes.
